Protein Determination
蛋白质浓度测定

从一道光、一组标准样品，推算未知溶液中有多少蛋白质。

根据 Experiment 2 Manual_W24 整理 · 初学者实验笔记

目的 · 为什么要测蛋白质浓度？

两瓶蛋白质溶液看起来可能一样，但里面的蛋白质含量可以不同。比较样品、安排后续反应或控制加入的蛋白质量之前，需要先知道浓度。

本实验学习用已知浓度的 BSA（牛血清白蛋白）作为参照，测出未知 BSA 溶液的浓度；同时比较不同蛋白质对检测方法的响应，理解为什么换一种方法可能得到不同结果。最后重复 Bradford 测定，练习准确移液、稀释与数据分析。

01 · 看懂信号

吸光度是仪器信号，不能直接当作浓度。

02 · 建立参照

用标准曲线把信号转换为浓度。

03 · 验证可靠性

扣空白、做重复、检查范围，再还原原液浓度。

看图理解 · 光如何告诉我们浓度？

A = log₁₀(I₀ / I) = −log₁₀(I / I₀)

A 是吸光度，没有单位。例如透过 10% 的入射光：A = −log₁₀(0.10) = 1.00。在线性适用范围内，Beer–Lambert 关系为：

A = εlc 或 A = alc

ε 是摩尔吸光系数，配合 mol/L；a 是质量浓度吸光系数，本实验可配合 mg/mL；l 用 cm。不能混用两种浓度与系数。例：若已知 a = 0.67 (mg/mL)⁻¹ cm⁻¹、l = 1.00 cm、校正后 A = 0.335，则 c = A/(al) = 0.500 mg/mL。数值为教学假设，不是你的实测结果。

三种方法 · 测量的是不同性质

方法信号来源与波长关键限制
A280 · 直接测量蛋白质本身的紫外吸收，主要来自 Trp 与 Tyr；280 nm核酸等会干扰；本实验用石英比色皿；不同蛋白响应不同
Bradford · 染料结合Coomassie G-250 与蛋白结合，蓝色形式信号增加；595 nmSDS 等洗涤剂会干扰；曲线可能弯曲
BCA · 化学显色蛋白参与 Cu²⁺ → Cu⁺，BCA 与 Cu⁺ 形成紫色复合物；562 nm还原剂（如 β-mercaptoethanol）会干扰；本手册未给出独立 BCA 操作实验

重点 1 · 先扣掉空白

Blank（空白）含水、缓冲液或显色试剂等背景成分，但不含待测蛋白。它回答：“没有蛋白时，这个体系本身会产生多少信号？”

A校正 = A样品 − A空白

教学例：样品 A595 = 0.42，空白 A595 = 0.06，则校正值 = 0.36。如果仪器已完成相应空白扣除，不要再次扣同一个背景。标准与未知样品必须用一致的处理方式。

重点 2 · 用标准曲线找到未知浓度

如果已验证的线性标准曲线是 y = mx + b，未知浓度 x = (y − b)/m。例：假设 y = 0.020x（x 用 μg/mL），y = 0.36 → x = 18 μg/mL。如果曲线弯曲，使用合适的拟合关系或范围内插值，不能强行套用直线。

只使用标准覆盖范围内的可靠信号

未知读数太高时先稀释再测，太低时调整稀释程度。不要向标准曲线之外盲目外推。手册也提醒高吸光度约 1.5–2.0 及显色响应变平时可能不可靠；具体上限依仪器与测定体系而定。

重点 3 · 连续稀释与原液换算

原液浓度 = 查曲线得到的样品浓度 × 稀释倍数

如果上述 18 μg/mL 来自 1/27 稀释的未知样品，原液 = 18 × 27 = 486 μg/mL = 0.486 mg/mL。

加入试剂的那一次稀释，要不要再乘 2？

本手册 Bradford 标准曲线 Table 2.4 的横轴采用加试剂前的样品浓度。标准与未知样品均取 125 μL 样品 + 125 μL 试剂。因此查曲线已得到加试剂前的浓度，不要再乘 2。如果自行把横轴定义为孔内最终浓度，就需要另外还原这一步 1:1 混合造成的稀释。先确认横轴定义再计算。

实验步骤 · 保留最关键的参数

Part A · A280 测未知 BSA
  1. 用石英比色皿比较 0.80 mg/mL BSA、0.40 mg/mL lysozyme 和 2.0 mg/mL gelatin 的紫外光谱，记录峰值、A280 与 A260。三者浓度不同，不能只看峰高就判断相对灵敏度。
  2. 从 2.0 mg/mL BSA 配制 1 mL 标准：0、0.25、0.50、0.75、1.00、1.25、1.50 mg/mL，每个标准做两份。
  3. 未知样品测原液，以及 1/2 与 1/4 稀释液；两个稀释条件分别做重复。
  4. 测 A280，处理空白并建立标准曲线，从有效范围内的读数求出未知浓度，再乘对应稀释倍数。

稀释计算例：2.0 mg/mL × V₁ = 0.50 mg/mL × 1.00 mL → V₁ = 0.250 mL，即 250 μL 原液 + 750 μL 水。

Part B · Bradford 微孔板测定
  1. 配制两管各 1 mL 的 100 μg/mL BSA：每管取 50 μL 的 2.0 mg/mL 原液 + 950 μL 水。
  2. 分别配制两组标准样品，并制备两组未知样品的 1/3 连续稀释系列。
  3. 每孔加入 125 μL 标准或未知样品；全部放好后，再加入 125 μL Bradford 试剂。混匀、避免气泡，尽量保持反应时间一致。
  4. 按课程程序读取 A595。标准和未知放在同一板上；不要为了复制数据而反复读取同一块板。
  5. 重复读数取平均，扣空白，选合适曲线，再使用范围内的未知读数计算原液浓度。

96-well plate · 样品放在哪个孔？

A1、A2：无蛋白空白。B1–H1 与 B2–H2：依次为 2、4、8、12、16、20、24 μg/mL 标准（加试剂前）。A3–H3 与 A4–H4：依次为 1/3 至 1/6561 的未知样品稀释。每孔取 125 μL 样品，再加 125 μL Bradford 试剂，总体积 250 μL。

完整 Example · 从读数找回 0.486 mg/mL

设原液的真实浓度为 0.486 mg/mL，暂时把这个答案遮住。我们模拟一次 Bradford 测定，只根据标准品和未知读数推算浓度，再检查是否找回给定值。以下所有数值都是教学假设，并非手册上的个人实验数据。

② 对未知样品做连续稀释

100 μL 原液 + 200 μL 水 → 1/3；混匀后再取 100 μL + 200 μL 水 → 1/9；再重复一次 → 1/27。对应 C3、C4 两个孔，每孔加 125 μL 稀释样品与 125 μL 试剂。

③ 取平均并扣空白

假设 C3 的 A595 = 0.414，C4 = 0.426。
平均 = (0.414 + 0.426)/2 = 0.420
校正吸光度 = 0.420 − 0.060 = 0.360。

④ 用标准曲线求稀释样品浓度

x = y/0.020 = 0.360/0.020 = 18.0 μg/mL。这个值处于标准范围内，并位于 16 与 20 μg/mL 标准之间，因此可以用这条假设曲线内插。

⑤ 还原到原液浓度

18.0 × 27 = 486 μg/mL = 0.486 mg/mL

结果与给定真实浓度一致。这里只乘 27，不再乘 2，因为标准曲线横轴已经是加试剂前的样品浓度，标准和未知经历了相同的等体积加试剂步骤。

⑥ 用另一个有效稀释检查

假设 1/81 稀释样品的平均 A595 = 0.180，扣空白后 0.120。查曲线：0.120/0.020 = 6.0 μg/mL；乘 81 → 486 μg/mL，同样找回原液浓度。实际实验中，不同有效稀释应给出相近结果；明显不一致时检查混匀、移液和曲线范围。

Part C · 为什么同样浓度的蛋白质信号不同？

比较 BSA、lysozyme 和 gelatin 在 A280 与 Bradford 中的响应。不同蛋白的氨基酸组成与染料结合性质不同，因此相同质量浓度不一定产生相同信号。

Bradford 比较样品从 0.1 mg/mL 各蛋白原液开始：125 μL 原液 + 375 μL 水，或 250 μL 原液 + 250 μL 水；各取 125 μL 加等体积试剂后，孔内最终浓度分别为 0.0125 与 0.025 μg/μL。这里是孔内浓度，与前面的标准曲线横轴定义不同。

灵敏度描述浓度变化带来的信号变化，不等于准确度。比较吸光系数时使用校正后的读数，并考虑浓度、光程以及是否处于有效响应范围；微孔板光程不能默认等于 1 cm。

Part D · 用已知样品检查自己的操作

重复 Part B2，这次样品的真实浓度已给出。对照测得值，检查标准品配制、移液、稀释倍数与数据分析。

若以真实浓度作为参考，误差百分比可写为：|测得浓度 − 真实浓度| / 真实浓度 × 100%。例如真实值 0.50 mg/mL，测得 0.54 mg/mL → 8%。这是教学例；课程若对“% difference”另有定义，按课程要求计算。

重点检查 · 什么时候需要重做？

  • 标准曲线 R² < 0.95：手册要求重做。高 R² 本身也不能保证测量准确，要同时检查重复样品与曲线范围。
  • 未知系列不规则，或没有可靠读数落在标准范围内：调整稀释条件并重测。
  • Part D 与已知浓度的差异超过 10%：先核对计算、拟合和稀释倍数；若计算正确，重新配制标准及样品进行测定。
  • 存在干扰物：根据样品成分选择方法。只有背景信号确实可加和时，空白扣除才可能补偿；不能假设扣空白能解决所有化学干扰。

补充方法 · BCA 蛋白质测定

独立补充：采用 Pierce BCA Protein Assay Kit 标准微孔板方案，不属于原课程手册的操作步骤，也不表示我在课程中实际完成过此项实验。

目的与原理

通过蛋白参与铜离子还原，再由 BCA 捕获 Cu⁺ 形成紫色信号，建立 A562 与蛋白浓度的对应关系。蛋白 → Cu²⁺ 转为 Cu⁺ → BCA–Cu⁺ 紫色复合物 → 读取 562 nm。

先确认试剂盒

下面针对普通 Pierce BCA 试剂盒；Micro BCA、Rapid Gold 等产品的用量和条件不同。还原剂与螯合剂会干扰普通 BCA，样品成分需核对所用产品的兼容性说明。

微孔板操作

  1. 配制 BSA 标准：0（空白）、25、125、250、500、750、1000、1500、2000 μg/mL；标准与未知尽量使用相同稀释介质，至少做两份重复。
  2. 按体积 A:B = 50:1 配工作液。
  3. 各孔加入 25 μL 标准或未知，再加 200 μL 工作液，振荡混匀 30 秒。
  4. 盖板，在 37°C 孵育 30 分钟；回到室温后读取 A562。
  5. 扣平均空白，以加试剂前的标准浓度建立曲线，使用范围内的未知读数换算。该方案工作范围为 20–2000 μg/mL，不能默认整个范围都严格线性。

BCA 显色会继续发展，应统一标准与样品的处理和读数时间。

方法来源：Thermo Fisher · Pierce BCA 官方说明书（MAN0011430，Rev. D）。

建议孔位 · 本页面的教学设计

在另一块板上，A1–A9 与 B1–B9 放上述九种标准（浓度由低到高），C1/D1 放未知的 1/2 稀释重复，C2/D2 放 1/4 稀释重复；其他孔备用。此布局为补充设计，与前面课程 Bradford 孔板图分开使用。

准备例子 · 标准与工作液

从 2 mg/mL BSA 配 500 μL 的 500 μg/mL 标准：V₁ = (500 × 500)/2000 = 125 μL 原液，再加 375 μL 稀释介质。其他标准同样使用 C₁V₁ = C₂V₂。

上面的布局共用 22 孔：18 个标准孔 + 4 个未知孔。至少需 22 × 200 μL = 4.40 mL 工作液。为移液损耗预留余量，可取 5.00 mL A + 0.100 mL B，得到 5.10 mL（50:1）。这是本页面的准备例子。

计算 Example · 找回 1.00 mg/mL

以下是自拟教学数据。设原液真实浓度为 1.00 mg/mL，先取 50 μL 样品 + 50 μL 稀释介质，得到 1/2 稀释。暂时不看答案，根据模拟读数求回原液：

750 μg/mL0.6050.525

假设该局部范围已验证可用直线 y = 0.000700x，其中 x 用 μg/mL。表格只是演示局部关系；实际需要完整标准数据并选择适合拟合。

  1. 未知两孔读数 0.424、0.436；平均 = 0.430。
  2. 扣空白：0.430 − 0.080 = 0.350。
  3. 查曲线：x = 0.350/0.000700 = 500 μg/mL。
  4. 还原 1/2 稀释：500 × 2 = 1000 μg/mL = 1.00 mg/mL。

不再乘 9：25 μL 样品与 200 μL 工作液混合确实把孔内浓度降至样品浓度的 1/9；但标准和未知同样经历此步骤，而横轴使用加试剂前的浓度，曲线已包含这一效果。仅还原事先做的 1/2 稀释。

如果 1/4 稀释的平均读数为 0.255，扣空白得 0.175，查曲线得 250 μg/mL，乘 4 仍为 1.00 mg/mL。两个有效稀释结果接近，是检查一致性的一种方式。
